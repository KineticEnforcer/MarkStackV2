# Getting Started

This section takes you from nothing to a working MarkStack site on your own computer, in about ten minutes.

## The path

1. **[Installation](/getting-started/installation)** covers what you need (Node.js and npm), how to get the code, and how to check that it works.
2. **[Quickstart](/getting-started/quickstart)** builds the site, previews it in a browser, and walks through writing a first page with automatic rebuilds.
3. **[Project Structure](/getting-started/project-structure)** explains every folder and file, and which ones you should and should not edit.
4. **[Set Up the Editor](/getting-started/set-up-the-editor)** creates the first administrator, starts the visual editor and publishes a change from the browser.

## Two ways to work

MarkStack supports two workflows and you can mix them freely, because both read and write the same `content/` folder.

| | Files and a text editor | Visual editor |
| --- | --- | --- |
| You write in | Any editor you like | A browser |
| You rebuild with | `npm run build` or `npm run watch` | The **Publish Changes** button |
| Good for | Developers, Git workflows, bulk changes | Writers, teams, quick edits |
| Needs sign-in | No | Yes, every editor has an account |

## What you need

| Requirement | Details |
| --- | --- |
| Node.js | Version 24 or newer |
| npm | Comes with Node.js |
| Git | Optional, to download the code and track changes |
| A browser | Any current browser |

> [!TIP]
> If you only want to read and write Markdown and publish static files, you can skip the editor entirely. Everything on the first three pages works without it.
